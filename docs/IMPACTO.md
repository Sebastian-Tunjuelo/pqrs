# Impacto estimado (orden de magnitud — demo)

Cifras orientativas para presentación; deben calibrarse con datos reales de cada secretaría.

| Métrica | Valor referencial |
|---------|-------------------|
| PQRS/día que recibe una secretaría típica | **X ≈ 40–120** (rango amplio según tamaño) |
| Tiempo actual por PQRS (clasificación + síntesis manual) | **Y ≈ 25–45 minutos** |
| Tiempo con la herramienta (validación + lectura de síntesis IA) | **Z ≈ 4–8 minutos** |
| Ahorro por funcionario | **N ≈ (Y−Z) × PQRS/semana** (ej. decenas de horas/mes si el volumen es alto) |
| Escalabilidad | **26 secretarías × mismo ahorro** proyecta impacto municipal si se adopta el mismo flujo |

**Supuestos:** la IA cubre bien el 80–90% de los casos rutinarios; el cuello de botella pasa a ser la validación humana y no la redacción desde cero.
